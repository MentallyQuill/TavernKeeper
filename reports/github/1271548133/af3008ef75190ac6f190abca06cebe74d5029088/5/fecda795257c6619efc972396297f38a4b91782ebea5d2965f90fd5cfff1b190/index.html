The file is documentation, not shipped executable code; nothing executes unless a reader manually copies the command. Destination, timing, and purpose are visible and proportionate to the project's stated distribution model. The supplied evidence shows no third-party endpoint, obfuscation, concealed execution, attacker-controlled input, or script content at all, so the scanner hit reflects a documented install pattern rather than demonstrated exposure.
