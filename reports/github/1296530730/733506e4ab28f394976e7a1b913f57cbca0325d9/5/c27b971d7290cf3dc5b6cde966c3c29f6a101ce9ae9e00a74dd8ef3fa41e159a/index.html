JavaScript analysis reported javascript.download-to-execution

Expected behavior · high confidence

The extension sends text to be translated through two paths: SillyTavern's own translation route and, for the optional Quick Google Translation setting, Google's public translation service. This is the feature described in the project's documentation, and nothing downloads and then runs new code.

Technical evidence

Scanner reason: JavaScript analysis matched static JavaScript security signal javascript.download-to-execution. The match applies to this repository.

Contextual assessment: The network primitives are a POST to the host's own translation route (with SillyTavern request headers) and a GET to Google's public translate endpoint, both with timeouts, abort signals, and chunked text payloads. These are the disclosed translation engines in the README; responses are parsed as strings/JSON for display, not executed. The presumed dynamic-sink correlation traces to runtime RegExp construction and jQuery/DOM manipulation with locally generated marker labels that are alphabet/hash-derived and regex-escaped, so no attacker-controlled code path to an execution sink exists in the supplied evidence.

Impact: none · Exploitability: unlikely

Developer action: none
