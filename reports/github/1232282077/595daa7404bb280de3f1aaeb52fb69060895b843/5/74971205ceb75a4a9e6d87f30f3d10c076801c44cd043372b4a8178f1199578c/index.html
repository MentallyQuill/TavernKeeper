Roleplay isolation recipe prevents host context leakage

low risk · high confidence

The plugin deliberately blocks the Claude SDK from reading host configuration files, tools, and permissions, ensuring roleplay content stays isolated from the host machine. This is a security-positive design choice.

Technical assessment

This prevents host machine files (CLAUDE.md, hooks, settings) from leaking into the model context.
