Related contextual observations

Icon picker interpolates campaign identifier into HTML without escaping

low risk · medium confidence

One small helper builds interface markup using an internal identifier without the same safety escaping used elsewhere in the project. This is a code-quality inconsistency, not an observed problem, since the identifier is created by the extension itself.

Technical assessment

The icon picker builder inserts the campaign identifier directly into an HTML attribute via template literal without the escaping utility, while the same identifier is escaped in the mobile file's parallel function only for world names. Campaign identifiers appear to be internally generated rather than attacker-controlled, so this is a quality inconsistency rather than demonstrated injection exposure. If campaign identifiers ever became user-supplied free text, attribute injection into the extension's own modal UI would be possible.

Impact: low · Exploitability: unlikely

Developer action: Apply the same HTML-escaping utility to the campaign identifier in attribute interpolation for consistency and defense in depth.

Campaign identifier interpolated into HTML attributes without escaping in several places

low risk · medium confidence

Several places build interface markup using an internal folder identifier without the safety escaping the project applies to names and colors elsewhere. The identifier is generated by the extension itself, so this is a consistency issue rather than an observed flaw.

Technical assessment

Multiple template literals insert the campaign identifier into data attributes and title text without the HTML-escaping utility, while user-facing names, colors, and icons are escaped. Campaign identifiers appear internally generated, so no attacker-controlled input path is demonstrated; this is an escaping-consistency gap. Were identifiers ever sourced from imported or user-entered free text, attribute or title injection within the extension's own modal would become possible.

Impact: low · Exploitability: unlikely

Developer action: Route the campaign identifier through the existing HTML-escaping utility wherever it is interpolated into attributes or title text.
