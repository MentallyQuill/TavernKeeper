JavaScript analysis reported javascript.xray.shady-link

Expected behavior · high confidence

The scanner flagged a line that looks like it might contain links, but it is just a list of text-transform token names like 'chars:' and 'last:'. The file performs only string operations with no network calls or external links of any kind.

Technical evidence

Scanner reason: JavaScript analysis matched static JavaScript security signal javascript.xray.shady-link. The match applies to this repository.

Contextual assessment: The JS-X-Ray shady-link heuristic matched string literals in the TRANSFORM_PREFIXES array (line 27), which contains colon-prefixed token names like 'chars:', 'last:', 'replace:', 'match:'. These resemble protocol-prefixed URLs to the heuristic but are purely string constants used to identify template transform tokens. Review of the entire file confirms zero network primitives: no fetch, XMLHttpRequest, WebSocket, URL construction, or dynamic import. The module is purely synchronous string transformation (trim, upper, lower, regex match, pad, etc.) with no external I/O as confirmed by the @contract annotation (external_io: none, purity: pure). The signal is a false positive from the heuristic misinterpreting colon-terminated string literals as link-like values.

Impact: none · Exploitability: unlikely

Developer action: none
