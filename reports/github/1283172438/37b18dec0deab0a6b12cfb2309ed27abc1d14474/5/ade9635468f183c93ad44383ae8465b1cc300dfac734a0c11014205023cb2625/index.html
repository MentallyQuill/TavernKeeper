Technical evidence

Scanner reason: JavaScript analysis matched static JavaScript security signal javascript.download-to-execution. The match applies to this repository.

Contextual assessment: The network primitives in the supplied source are same-origin fetch calls to the SillyTavern host's own file endpoints, used with request headers to upload a base64-encoded JSON backup of the extension's legacy folder data and to delete that backup later. This matches the README's disclosed behavior of keeping a temporary legacy-data backup file. The upload body derives from the extension's own settings serialization, not from remote content, and the fetch response is only parsed for a path string that is returned or later passed to the delete call. The remaining flagged constructs are UI rendering, settings migration, and preset-manager calls consistent with the stated folder-organization purpose.
