JavaScript analysis reported javascript.xray.unsafe-regex

Minor caution · high confidence

A scanner flagged some text-matching patterns as potentially slow. These patterns only parse short color strings that the browser itself formats, so in practice they cannot be made to hang the app by any outside party.

Technical evidence

Scanner reason: JavaScript analysis matched static JavaScript security signal javascript.xray.unsafe-regex. The match applies to this repository.

Contextual assessment: The flagged expressions are anchored color-parsing regular expressions applied to strings produced by the browser's computed-style resolution of a color value. Inputs are short, browser-normalized color strings rather than arbitrary attacker-controlled text, and the patterns are linear with bounded alternations, so no catastrophic backtracking path is demonstrated. At worst, unusual input could cause a brief tab slowdown, which is a recoverable local performance issue only.

Impact: low · Exploitability: unlikely

Developer action: none

JavaScript analysis reported javascript.download-to-execution

Expected behavior · high confidence

The code downloads saved color themes from the app's own server and applies those colors to the interface. Although a scanner linked the download with dynamic code patterns, the downloaded data is only used to set colors, never run as code. This is exactly what a theme feature is supposed to do.

Technical evidence

Scanner reason: JavaScript analysis matched static JavaScript security signal javascript.download-to-execution. The match applies to this repository.

Contextual assessment: The network retrieval in this file is a same-origin request to the SillyTavern settings endpoint, using the host's own request headers, to look up a saved theme by name. The response is used only to copy color strings into CSS custom properties and attribute values on color picker elements. The correlated 'execution sink' is dynamic property assignment such as the event-dispatch override on a picker element and timer-based reapplication, not evaluation of retrieved content. Retrieved theme values are never passed to script evaluation, HTML construction, or code generation, and the monkey-patched fetch wrapper only appends locally computed color keys to the host's own theme-save requests. This behavior matches the project's stated theme-integration purpose and stays within the host origin.

Impact: none · Exploitability: unlikely

Developer action: none
