JavaScript analysis reported javascript.download-to-execution

Expected behavior · high confidence

A scanner noticed this file both makes network requests and contains something it thought could run code. In reality, the requests only go to the SillyTavern app running on your own machine to save and load theme colors, and the downloaded data is only used to set colors, never executed as code.

Technical evidence

Scanner reason: JavaScript analysis matched static JavaScript security signal javascript.download-to-execution. The match applies to this repository.

Contextual assessment: The network primitive is a same-origin request to the local SillyTavern settings endpoint, returning JSON that is read only for theme names and color values, which are then applied as CSS custom properties and picker attributes. The apparent execution sink is a per-element event-dispatch suppression shim and a wrapped fetch that attaches current theme colors to theme-save requests; neither evaluates retrieved content as code. There is no dynamic code execution, remote script loading, or attacker-controlled input reaching either construct, and the behavior is proportionate to the extension's stated theme integration purpose. The correlation is coincidental, not a demonstrated exposure.

Impact: none · Exploitability: unlikely

Developer action: none
