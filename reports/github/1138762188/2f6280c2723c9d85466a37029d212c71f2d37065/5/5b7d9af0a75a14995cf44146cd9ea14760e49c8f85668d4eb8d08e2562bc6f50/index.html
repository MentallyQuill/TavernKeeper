Minor cautions

zizmor reported adhoc-packages

Minor caution · high confidence

The project's build recipe downloads whatever the newest version of a helper tool happens to be each time it runs, instead of a locked, known version. Nothing shown is harmful today, but if that helper package were ever hijacked, its code could run inside this project's build automation.

Technical evidence

Scanner reason: zizmor matched workflow-security rule adhoc-packages. The match applies to this repository.

Contextual assessment: The workflow installs a globally scoped npm package by name with no version or integrity lock. The job has read-only repository permissions, runs only on changes to this workflow file or manual dispatch, and references no secrets or untrusted input, so no concrete exposure is shown. The residual concern is the standard unpinned-remote-dependency CI weakness: a compromised or substituted package publication would execute attacker code inside the automation runner.

Impact: low · Exploitability: unlikely

Developer action: Pin the CLI to an exact released version with a checksum or lockfile so CI cannot silently pull a different or hijacked package build.

JavaScript analysis reported javascript.xray.unsafe-regex

Minor caution · low confidence

The code uses pattern-matching expressions to pull structured text (like fenced code blocks and numbers) out of model replies. Pattern matching is normal here, but on unusual input a poorly behaved pattern could make the user's own tab hang momentarily. That kind of self-inflicted slowdown is the realistic worst case shown, which is minor.

Technical evidence

Scanner reason: JavaScript analysis matched static JavaScript security signal javascript.xray.unsafe-regex. The match applies to this repository.

Contextual assessment: Ten regex literals were flagged in the bundle, including fenced-code-block extraction and numeric-literal validation over model-produced or user-provided text. The scanner flags these as potential denial-of-service patterns, but no catastrophic backtracking construction is visible in the supplied windows, and the affected code runs in the user's own browser tab, so the concrete harm ceiling is a local slowdown or temporary freeze of the user's session, which calibrates to low impact.

Impact: low · Exploitability: plausible

Developer action: none
