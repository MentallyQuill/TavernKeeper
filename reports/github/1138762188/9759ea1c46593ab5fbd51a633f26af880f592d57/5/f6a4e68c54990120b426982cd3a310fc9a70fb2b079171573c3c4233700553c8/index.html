JavaScript analysis reported javascript.xray.unsafe-regex

Minor caution · medium confidence

Some text-matching patterns in the bundled code could be slow with unusually crafted input, but no evidence shows a way for an attacker to actually cause this in normal use, and the worst case is a briefly stuck tab.

Technical evidence

Scanner reason: JavaScript analysis matched static JavaScript security signal javascript.xray.unsafe-regex. The match applies to this repository.

Contextual assessment: The flagged regexes are part of bundled third-party parser libraries (Handlebars lexer token patterns, numeric and markup validators) in the generated bundle. The scanner did not retain the matched literals and no evidence shows attacker-controlled input reaching a pathologically backtracking expression under realistic chat-tracker usage. Worst plausible outcome is a slow or momentarily unresponsive tab on crafted input, which is a self-recoverable local denial of service.

Impact: low · Exploitability: unlikely

Developer action: Optionally audit the flagged expressions for linear-time behavior if untrusted tracker content is parsed with them; otherwise no action required.

JavaScript analysis reported javascript.xray.unsafe-regex

Minor caution · medium confidence

Some pattern-matching code in the bundled libraries could run slowly if fed deliberately weird text. The worst outcome is the extension's own tab briefly lagging; there is no evidence of a way for an outside party to trigger this.

Technical evidence

Scanner reason: JavaScript analysis matched static JavaScript security signal javascript.xray.unsafe-regex. The match applies to this repository.

Contextual assessment: The matched patterns are parsing regular expressions from bundled template, JSON, and XML libraries. Most are linear or anchored patterns over short strings, but a few with nested repetition and capture groups could exhibit backtracking slowdown on pathologically crafted input. In this client-side extension the inputs are locally generated tracker content and user-imported module files, so any resulting delay is a recoverable local slowdown of the user's own tab and does not constitute a concrete security harm. No attacker-controlled remote input path to these expressions is demonstrated.

Impact: low · Exploitability: unlikely

Developer action: Optionally audit the bundled parser dependency for known regex denial-of-service advisories and update it during routine maintenance; no urgent change is required.
