Minor cautions

OpenGrep reported tavernkeeper.download-and-execute.shell-pipeline

Minor caution · high confidence

This is a setup script for people working on the project's code, not something that runs when you use the extension. If your computer lacks a tool called bun, the script downloads and runs the tool's own official installer from the maker's website. That is a common but slightly risky practice, because the script does not verify the download's contents first; it simply trusts the source. The evidence shows no sign that the source is anything other than the official one, and only a developer choosing to run the setup script is affected.

Technical evidence

Scanner reason: OpenGrep matched static-analysis rule tavernkeeper.download-and-execute.shell-pipeline. The match applies to this repository.

Contextual assessment: The flagged line is a developer-environment bootstrap fallback: when the bun runtime is missing, the script first tries a package-manager install and, on failure, pipes the official bun installer over TLS into a shell. This is the runtime vendor's documented install method, is confined to a repository setup script that a developer runs deliberately on their own machine, is not part of the shipped extension code, and is disclosed in the surrounding comments. The genuine weakness is that the downloaded script is executed without an integrity check or version pin, so the script trusts the vendor's endpoint and the network path; compromising that endpoint or a suitably positioned intermediary would yield code execution in the developer environment. However, no such compromise is evidenced, the destination is the vendor's own site over TLS, and no attacker-controlled trigger reaches this path, so exposure is not demonstrated.

Impact: low · Exploitability: unlikely

Developer action: Consider installing the runtime via a package manager only, or verifying the downloaded installer (checksum or pinned version) before executing it, so the setup script does not rely solely on trust in the download endpoint.
