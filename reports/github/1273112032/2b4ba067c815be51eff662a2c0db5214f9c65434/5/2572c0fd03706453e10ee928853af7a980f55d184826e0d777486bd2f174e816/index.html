JavaScript analysis reported javascript.download-to-execution

Expected behavior · low confidence

This test script checks that a local preview server is running and then launches it. It only connects to its own computer, not the internet, and only runs its own code. There's no way for an attacker to exploit this.

Technical evidence

Scanner reason: JavaScript analysis matched static JavaScript security signal javascript.download-to-execution. The match applies to this repository.

Contextual assessment: The scanner correlated a network retrieval primitive (fetch to localhost) with a code execution sink (spawn). The fetch is used to poll a local test server until it becomes available, and spawn runs a known local script (serve-expanded-interface-preview.mjs) in the same repository. There is no dynamic code execution from untrusted network data; the code path is entirely self-contained for testing. No vulnerability exists.
