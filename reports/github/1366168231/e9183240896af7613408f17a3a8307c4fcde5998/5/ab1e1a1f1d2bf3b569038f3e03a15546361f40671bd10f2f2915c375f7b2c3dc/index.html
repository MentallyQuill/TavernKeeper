Expected behavior · high confidence

The extension fetches a picture that the host app's own image generator produced, checks that it is really an image of a reasonable size, and shows it as an NPC portrait. Nothing downloaded is ever run as code. This is exactly what the feature promises in the README.

Technical evidence

Scanner reason: JavaScript analysis matched static JavaScript security signal javascript.download-to-execution. The match applies to this repository.

Contextual assessment: The flagged network retrieval is a same-origin fetch of an image URL returned by the host's own SillyTavern Image Generation pipeline. The response is constrained to an image content type, capped at 16 MB, converted into a File object, and only ever used as an NPC portrait preview or attachment. The correlated 'execution sink' in the window is image decoding via Image/canvas and DOM element assignment, not evaluation of fetched content as code. No eval, Function construction, or command execution consumes network data. This data flow is proportionate to the extension's stated portrait-generation feature.
