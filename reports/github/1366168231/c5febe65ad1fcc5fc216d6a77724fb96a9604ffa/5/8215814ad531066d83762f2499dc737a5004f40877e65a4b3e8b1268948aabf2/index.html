JavaScript analysis reported javascript.download-to-execution

Expected behavior · high confidence

This code lets the extension fetch the picture it just asked SillyTavern's image generator to create, checks that it really is a small image file, and saves it as the NPC's portrait. Nothing in it runs downloaded content as code; the download is only used to display and store a picture, and it comes from the user's own SillyTavern server.

Technical evidence

Scanner reason: JavaScript analysis matched static JavaScript security signal javascript.download-to-execution. The match applies to this repository.

Contextual assessment: The flagged region implements the NPC portrait generation workflow: the extension requests an image through the host's SillyTavern Image Generation API, then downloads the returned image URL with a same-origin fetch, validates that the response is an image under 16 MB, and converts it to a File object for the dossier portrait. The correlation between a network primitive and an apparent execution sink reflects the scanner pairing the fetch with standard DOM image/canvas/File handling, not dynamic code execution: the retrieved bytes are only decoded as an image, rendered through an Image element or canvas encoder, and never evaluated as script. The URL originates from the trusted host generation API, is resolved against the page origin, and the download is gated by extensive stale-session and revision checks before any state is written.

Impact: none · Exploitability: unlikely
