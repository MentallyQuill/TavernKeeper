Without identifying the specific affected package, runtime reachability and attacker-controlled input paths cannot be confirmed. The extension operates in a browser context within SillyTavern, limiting the attack surface for most server-side dependency vulnerabilities.

Impact: low · Exploitability: unlikely

Developer action: Run an updated dependency audit with package names visible, identify whether the affected package is a production or dev dependency, and upgrade if a patched version is available.
