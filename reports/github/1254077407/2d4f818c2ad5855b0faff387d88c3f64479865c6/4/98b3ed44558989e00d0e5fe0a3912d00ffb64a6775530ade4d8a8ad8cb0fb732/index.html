It runs entirely on your own computer and does not send data anywhere or change files. A strange message could at most briefly pause the page.

Technical evidence

Scanner reason: JavaScript analysis matched static JavaScript security signal javascript.xray.unsafe-regex in this repository.

Contextual assessment: The flagged pattern at line 479 is a human-readable date parser used by parseSceneDateParts to extract scene dates from roleplay message content. No concrete attacker-controlled path to data loss, exfiltration, or code execution is demonstrated.
