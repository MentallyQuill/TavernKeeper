Related contextual observations

Unauthenticated CDP relay can bind to all interfaces

low risk · medium confidence

If the user configures the tool to be reachable beyond their own computer, anyone on the same network could control the browser session it manages. The tool does warn about this, but the exposure is still a risk if the warning is ignored.

Technical assessment

The relay and Chrome DevTools Protocol port have no authentication. When the bind address is not loopback, any device on the same network can drive the logged-in browser session and access its JanitorAI cookies. The code does print a warning when binding to all interfaces, which is good practice, but the default or misconfigured bind could expose full browser control to LAN peers. This is a configuration risk rather than malicious behavior, and the warning mitigates it partially.

Impact: medium · Exploitability: plausible

Developer action: Consider defaulting the bind address to loopback and requiring an explicit opt-in flag for LAN-wide binding, rather than relying on a console warning after launch.
