Contextual assessment: The scanner flagged a regular expression it treats as potentially unsafe for catastrophic backtracking. No denial-of-service path via these expressions is demonstrated. The evidence window is truncated, but every visible pattern-matching expression in the supplied source is safe.

JavaScript analysis reported javascript.download-to-execution

Expected behavior · medium confidence

The scanner noticed that the file both downloads something and runs a command-like operation, and flagged that combination. Here the download only reads the extension's own translation files from the same SillyTavern server, and the command is a standard browser feature for inserting text into the text box you are typing in, so undo keeps working. Neither part runs downloaded content or executes programs, and nothing downloaded is ever executed.

Technical evidence

Scanner reason: JavaScript analysis matched static JavaScript security signal javascript.download-to-execution. The match applies to this repository.

Contextual assessment: This is a same-file correlation rule, not a data-flow finding. The visible network retrieval fetches static locale JSON from the extension's own directory on the same origin; the locale identifier is matched against the extension's own manifest and then validated against a strict short format before being used in a path. The fetched data is passed only to SillyTavern's translation system as string data. The visible execution-like primitive is the deprecated DOM text-editing command used to insert or delete text in the focused textarea so the browser's undo history is preserved; it edits editor text only and does not evaluate code, run shell commands, or create markup. No path exists in the supplied source in which fetched bytes reach an evaluation or command-execution sink, and the extension's stated purpose (a formatting toolbar over the message input) matches exactly these capabilities.
