Technical evidence

Scanner reason: zizmor matched workflow-security rule cache-poisoning in this repository.

Unpinned GitHub Action references in CI workflow

low risk · medium confidence

Two actions in the workflow are referred to by their version numbers, which is convenient but slightly risky because the meaning of a version number can change. Pinning to a specific commit is safer, though the risk is small for these official actions.
