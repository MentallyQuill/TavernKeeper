Related contextual observations

Raw error message reflected to Discord channel

low risk · medium confidence

If something goes wrong, the bot posts the raw error text into the Discord chat. Usually harmless, but if an error message ever contained private details, those details would be visible to users in the channel.

Technical assessment

The error handler interpolates error.message directly into the followup text sent to Discord. If an underlying error message contains sensitive internal detail (paths, token fragments, stack traces), that text could be exposed in the Discord channel. This is a low-severity information-disclosure concern, not credential exfiltration.

Impact: low · Exploitability: unlikely

Developer action: Sanitize or generalize error messages before sending them to Discord; log full errors server-side only.
